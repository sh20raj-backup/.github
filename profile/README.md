## What is this?

In October 2026, every repository from **@SH20RAJ** was consolidated into **@playlikeboy**. This organisation is the permanent backup of that body of work: **335 repositories** — all personal projects plus every organisation collection — cloned with **all branches, tags and commit history**, with commits authored as **@playlikeboy** and original dates preserved.
